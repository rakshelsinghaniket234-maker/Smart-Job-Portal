# Smart Job Portal

A web-based Job Portal developed using Java, JSP, Servlets, JDBC and MySQL.

## Technologies Used

- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Features

- User Registration and Login
- Job Search
- Job Listing
- Job Posting
- Apply for Jobs
- Update Job Details
- Delete Jobs
- View Applications
- User Profile
- Session Management
- Authentication Filter
- Admin Filter
- CRUD Operations
- MySQL Database Connectivity
